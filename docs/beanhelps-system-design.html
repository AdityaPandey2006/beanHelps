01 · Architecture

High-level architecture

A two-application JavaScript system: the browser SPA owns presentation and navigation; the API owns identity, access rules, domain logic, and persistence.

Browser boundary

Stores JWT in localStorage, attaches it as Authorization: Bearer …, renders public/protected routes, and redirects by role/onboarding state.

API boundary

Helmet, CORS, request parsing, logging, validation, JWT authentication, role authorization, controllers, services, not-found and centralized error handling.

Data boundary

Mongoose schemas implement references, enums, defaults, timestamps, validation, and compound indexes. Passwords are hashed with bcrypt before storage.

Decision detail

Beaner (support seeker)

  1. Signup as beaner, or log in.
  2. If no onboarding indicators exist, collect age range, languages, location, group size, struggles, tags and description.
  3. Land on /home.
  4. Join recommended/explored forums; read and create posts/comments after joining.
  5. Browse/join a support group or request matching; chat, see members and meetings when authorized.
  6. Report unsafe content when needed.

Beanpist (therapist)

  1. Signup as beanpist, or log in.
  2. If incomplete, submit specializations, languages, experience, availability and credential URL.
  3. Land on /therapist/home; status is pending until admin review.
  4. Browse community content.
  5. Once verified, create therapist resources, meetings and therapist-led groups.

Admin

  1. Log in with an existing admin account (public signup offers only beaner/beanpist).
  2. Land on /admin.
  3. Review pending therapists and set verification status.
  4. Review open/reviewing reports.
  5. Resolve/dismiss reports and apply moderation actions.

Consistency note: most relationships are application-managed references rather than database-enforced foreign keys. The support-group member count is denormalized and updated by service logic, so concurrent join/leave operations deserve transactional or atomic-update protection in a production hardening pass.
